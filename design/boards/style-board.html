    Copy this prompt into Claude Code

    In the terminal or your IDE. Claude counts your usage without changing any file, and replies with a few lines of totals.

    Count my Claude Code token use for the last 30 days, for ai-co2.
This is read-only: don't create, change, move or delete any file.

1. Run the Python script below exactly as it is.
2. If Python 3 isn't installed, write your own code that follows
   the same rules:
   - read ~/.claude/projects/**/*.jsonl, including subagents/
   - keep only entries from the last 30 days
   - count each message once: match on message.id + requestId
     and keep the entry with the highest output token count
   - add the tokens up per model
3. Reply with the result block only, exactly as printed.

python3 - <<'EOF'
import glob, json, os
from collections import defaultdict
from datetime import datetime, timedelta, timezone

now = datetime.now(timezone.utc)
since = now - timedelta(days=30)
root = os.path.expanduser("~/.claude/projects")
best = {}
for path in glob.glob(os.path.join(root, "**", "*.jsonl"), recursive=True):
    with open(path, encoding="utf-8", errors="ignore") as f:
        for line in f:
            try:
                e = json.loads(line)
                m = e.get("message") or {}
                u = m.get("usage") or {}
                t = datetime.fromisoformat(e["timestamp"].replace("Z", "+00:00"))
            except Exception:
                continue
            if not u or t < since:
                continue
            key = (m.get("id"), e.get("requestId"))
            old = best.get(key)
            if old is None or u.get("output_tokens", 0) > old[1].get("output_tokens", 0):
                best[key] = (m.get("model", "unknown"), u)

totals = defaultdict(lambda: [0, 0, 0, 0])
for model, u in best.values():
    s = totals[model]
    s[0] += u.get("input_tokens", 0)
    s[1] += u.get("cache_creation_input_tokens", 0)
    s[2] += u.get("cache_read_input_tokens", 0)
    s[3] += u.get("output_tokens", 0)

print(f"ai-co2 v1 | {since:%Y-%m-%d} to {now:%Y-%m-%d}")
for model, s in sorted(totals.items()):
    print(f"{model} | in {s[0]} | cache_write {s[1]} | cache_read {s[2]} | out {s[3]}")
EOF

Why it looks like this

  • The whole prompt is one click away, so nobody pastes something they haven’t seen.
  • The answer is checked as you paste it: first the format, then whether the numbers are plausible.
  • A problem says what went wrong and what to do next.
  • The card stays in ink. The accent is kept for your numbers and the one main action.

The prompt, the script and the answer format are drafts.

Type and colour

What’s kept from the reference, what’s changed, and the pieces everything above is built from.

Kept from the reference

  • Warm paper and navy-black ink.
  • Deep navy panels with a faint grid, for the moments that matter.
  • Heavy headings with tight spacing.
  • Figures in JetBrains Mono.
  • Rounded cards, pill buttons and a floating dark pill.

Changed

  • Schibsted Grotesk for every word. The reference asks for Nohemi, which never loads, so visitors actually see Helvetica.
  • Lime instead of blue and cyan, used only for your data and the main action. Aqua is the quieter option, closer to the reference.
  • No gradient text, no glows, no small spaced-out labels above headings.
  • Glass only on the pinned bar, where it keeps text readable over the page.
