The CO₂ of your AI use

ai-co2 turns what you spent in Claude Code or in ChatGPT into a CO₂ range for the last 30 days, then shows how to cut it.

Runs in your browser. Nothing is uploaded.

Your data

Choose Claude Code or ChatGPT. The page then works with the one you pick.

Claude Code

  1. 1

    Copy this prompt into Claude Code

    In the terminal or your IDE. Claude counts your usage without changing any file, and replies with a few lines of totals.

    Count my Claude Code token use for the last 30 days, for ai-co2.
This is read-only: don't create, change, move or delete any file.

1. Run the Python script below exactly as it is.
2. If Python 3 isn't installed, write your own code that follows
   the same rules:
   - read ~/.claude/projects/**/*.jsonl, including subagents/
   - keep only entries from the last 30 days
   - count each message once: match on message.id + requestId
     and keep the entry with the highest output token count
   - add the tokens up per model
3. Reply with the result block only, exactly as printed.

(The script follows here in the real prompt.)
  2. 2

  1. In ChatGPT, open Settings › Data controls › Export data.
  2. Open the email you get and download the ZIP. The link works for 24 hours.
  3. Drop the ZIP below. It’s read in your browser, and nothing is uploaded.

Reading your export in this tab: 412 of 1,284 conversations. Large exports take a minute.

What leaves your computer

  • From ChatGPT: nothing. The export is read in this browser tab.
  • From Claude Code: only the totals. Your own Claude Code does the counting, so they pass through Claude like any other message.
  • Afterwards: nothing is kept. Closing the tab clears everything.

Your result

The last 30 days, as a range. It moves whenever you change anything on this page, and a small copy stays on screen while you scroll. Here it waits in the column on the right.

Ways to cut

Picked from your own numbers, biggest saving first.

Fund carbon removal

Cutting comes first. If you also want to pay for removing or avoiding CO₂, here are three kinds. It’s a contribution: it doesn’t cancel what you used. Funding removal of your 3.7–34 kg would cost about €0.37–16, depending on the method.
